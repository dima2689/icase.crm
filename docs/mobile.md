# Приложение для телефона (сотрудники)

CRM устанавливается на телефон как приложение (PWA) прямо с адреса CRM — без Google Play и App Store.

- **Android (Chrome):** открыть адрес CRM → карточка «Установить» на Сводке или меню ⋮ → «Установить приложение».
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».

Что есть:
- нижняя панель: Касса, Ремонт, **Скан**, Задачи, Ещё (остальные разделы);
- сканер камерой: штрихкоды EAN/UPC, Code 128/39/93, ITF, QR, DataMatrix. На Android — встроенный распознаватель, на iPhone — модуль ZXing (`js/vendor/zxing.min.js`, грузится только при первом скане);
  - на экране с полем сканирования (касса, приёмка, ввод IMEI в документах) код уходит в это поле; в приёмке и при вводе IMEI сканирует подряд;
  - на остальных экранах — поиск по базе: экземпляр по IMEI/SN, товар по штрихкоду, ремонт или продажа по номеру;
  - фонарик, смена камеры, ручной ввод;
- ярлыки на иконке: Сканировать, Касса, Ремонт, Задачи;
- без сети приложение открывается (оболочка в кэше, `sw.js`), показывает предупреждение; данные базы не кэшируются и без сети не сохраняются. После появления связи данные перезагружаются.

Требования: CRM должна открываться по **https** (Cloudflare Pages подходит) — иначе камера и установка не работают.
При выпуске новой версии поменять `VER` в `sw.js`, чтобы обновился кэш оболочки.

## Рабочие места
Одна база и один код, три входа (у каждого своя иконка на телефоне):
- **Касса** — `?ws=pos`: продажа, возврат, смена, приём и выдача ремонта с экрана кассы, заказы, клиенты, задачи, ценники. По умолчанию для продавца.
- **Сервис** — `?ws=service`: доска ремонтов, запчасти, клиенты, задачи. По умолчанию для мастера.
- **CRM** — `?ws=crm`: всё. По умолчанию для владельца, управляющего, кладовщика.

Переключатель внизу меню (если прав хватает на несколько мест); выбор запоминается. Касса и Сервис не загружают финансы, документы склада, закупки, журнал — открываются быстрее. Права на данные по-прежнему проверяет база.
