# База IMEI: что за устройство по коду

Где работает: приёмка (окно «Устройство Apple»), новый ремонт (поле IMEI → «Устройство»), выкуп/комиссия, trade-in на кассе, «Настройки → Каталог Apple → Проверить код», сканер камерой.

Как определяется:
1. **IMEI → модель** по справочнику TAC (первые 8 цифр IMEI): ~114 тыс. моделей всех брендов, Apple ~9 тыс. кодов, включая iPhone 17 и Air. Источник — github.com/MoazEb/tac-database (лицензия MIT). Память и цвет по IMEI производитель не кодирует.
2. **Артикул с коробки** (MTUV3ZD/A, в штрихкоде — 1PMTUV3ZD/A) → модель, память, цвет, SIM. Однозначный, заполняет всё сразу.
3. **Обучение на своих приёмках**: каждый принятый экземпляр (любым способом — приёмка, выкуп, импорт) запоминает связку «код → товар». Память/цвет по IMEI подставляются, когда они совпали минимум в 3 приёмках (≥90%); по артикулу — с первого раза. Иначе показывается подсказка «чаще всего: 256 ГБ».

Дополнительно: проверка контрольной цифры IMEI (опечатки), предупреждение «уже в базе: … продан / на складе» с кнопкой истории.

Таблицы: `tac_db`, `device_hints`, колонка `units.part_no`; функции `device_lookup(code)`, `tac_stats()`, триггер `units_learn`.

Обновить справочник TAC (SQL Editor Supabase, без ограничения по времени):
```sql
select net.http_get(url := 'https://raw.githubusercontent.com/MoazEb/tac-database/main/tac_full.csv', timeout_milliseconds := 120000); -- вернёт id
select tac_load_csv((select content from net._http_response where id = <id>));
delete from net._http_response where id = <id>;
```

Платные сервисы проверки по IMEI (память, цвет, статус блокировки iCloud/Find My, гарантия) можно подключить отдельно — ключ хранится в Vault, проверка ~по запросу.
